# 俗称歧义的答复规则

名称解析应区分已确认别名、存在多义的泛称和未收录名称。只有在来源明确记录对应关系时，才能把俗称归一化到具体物品；字面接近或同一段资料出现过，不能证明它们是同一对象。

## 奶杖

2026-10-27 的维护者业务抽查确认：“奶杖”可能指多种武器，应先追问具体是哪一把。

机器人遇到未限定的“奶杖”时，应询问具体武器名称、阶级或其他足以区分对象的条件。不能直接默认成传说圣杖，再提供其材料或属性。源文件中某条配方名称含“奶杖”，也不代表所有玩家都用这个俗称指向同一种武器。

明确完整配方名与武器种类后，才核对相应配方；仍缺绑定状态或转化来源时，再询问剩余条件。未映射的材料名保留原始标识并说明未知，不能自行补成中文名。

这是一条歧义处理规则，不是新增物品对应关系，不改变现有词条审核状态。来源记录不包含聊天身份、群号或原始聊天。
