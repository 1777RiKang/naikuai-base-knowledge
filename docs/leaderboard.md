# 贡献排行榜规则

## 计分

一个独立且当前审核状态为 confirmed 的词条计 1 分，包括已指定归属的种子词条，以稳定 id 去重。
多个义项、别名、字数、提交次数和 PR 数不额外加分。纠错与审核暂不单独计分。
词条退回 draft、转 disputed 或 deprecated 时不计入当前总分；重新确认后恢复。
语义重复由维护者审核，不能通过拆文件或换 id 重复计分。

`credits/m0-seed-ids.json` 是初始 50 条数据的固定清单，后续不应把新词条加入其中。
维护者已将这批数据归属指定为“空调房里晒太阳”，记录在 `credits/m0-seed-attribution.json`。
已确认种子计 1 分；draft/disputed 种子单列“待审”，确认后自动转入积分；deprecated 不计分。
榜单 JSON 保存已确认和待审的词条 ID，完整表格展示两者及合计，方便核对。

## 归属与公开贡献名

非种子词条由程序从完整 Git 历史查找首次新增词条的提交，通过 GitHub API 确认其已合并 PR，
把积分归给该 PR 作者的 GitHub 数字用户 ID。不会把 merge commit 作者、审批者或后续修改者当作原作者。
非种子词条未找到来源 PR 时工作流报错；初始种子通过维护者指定记录归属。

贡献者在首次词条的 `contributors` 中填写 annotator 的 name，作为自愿公开的贡献名。
同一 PR 多人协作时，本版积分只归该 PR 作者；其他贡献者仍可在词条中署名。
同一账号只占一个榜单位置，同名不同账号分别列出；同分并列，以数字 ID 排序。
没有改名配置时，使用该账号最新引入并已计分词条中的原始贡献名。

如需统一贡献名，提交 PR 修改 `credits/display-names.json`，把自己的 GitHub 数字用户 ID
映射到自选公开名称。格式示意：`{"42": "自选公开贡献名"}`。
维护者核对 PR 作者 ID；本人申请才能改名，维护者也可按本人明确请求代改。
数字 ID 可以在 GitHub 用户 API 的 id 字段查询，不使用 QQ 号或邮箱识别身份。

贡献名不能含控制字符、联系方式、凭据或冒用身份。聊天证据中仍禁止保留玩家昵称。

## 更新与文件

main 每次合并后运行 leaderboard 工作流。它先校验已审核主分支，再生成：

- leaderboard.svg：README 内显示前 15 名；超长贡献名在图片中省略，完整榜单保留全名。
- leaderboard.md：完整可读榜单。
- leaderboard.json：全部积分、贡献者 ID、贡献名及其计分词条 id，便于复核。

以上文件发布到独立的 leaderboard 分支，包含来源提交和生成时间，README 引用该分支图片。
不为更新榜单向 main 写自动提交；外部 PR 校验没有仓库写权限。
图片可能受 GitHub 缓存影响稍晚刷新。可在 Actions 手动运行工作流重建。
生成失败时保留上次成功榜单，并在 Actions 显示失败。
